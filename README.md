# Site da Léa Foto e Arte

### Sobre o Projeto

Esse é um projeto para a disciplina SCC0219 - Introdução ao Desenvolvimento Web no primeiro semestre de 2026.

O objetivo da primeira entrega é desenvolver um protótipo interativo com HTML e CSS.

## Sobre a Empresa

A Léa Foto e Arte é uma empresa de papelaria personalizada especializada em festas infantis, que atua no mercado desde 2009. Seus produtos principais são convites, topos de bolo, toppers, forminhas de docinho, tubetes, varal de personagens e adesivos variados. Na época do volta às aulas também oferece etiquetas escolares, agendas e tags para mochilas.

## Telas

Desenvolvemos em HTML e CSS as telas de:
- Página Inicial
- Comprar por Temas
- Listar Produtos (resultados de query no BD)
- Produto Individual
- Sobre a Empresa
- Políticas da Loja

Também desenvolvemos o design de um Backoffice no FIGMA com:
- Gerenciamento de Produtos
- Gerenciamento de Vendas
- Modificação do Frontend do Site Público
- Geração de Relatórios

Pode ser acessado [clicando aqui](https://www.figma.com/design/4Xzd9YBH3SzxHnXRrlUK7k/Site-L%C3%A9a-Foto-e-Arte?node-id=185-2231&m=dev).

## Próximos Passos

Converter o projeto em React para facilitar a componentização e desenvolver o backend.
